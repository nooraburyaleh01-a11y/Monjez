# منجز — GitHub + Vercel

واجهة منجز تُنشر على Vercel، مع إبقاء Google Sheets قاعدة البيانات وGoogle Apps Script كخدمة خلفية. الواجهة لا تستخدم `google.script.run`؛ بل تستدعي `/api/monjez`، وتقوم وظيفة Vercel باستدعاء Google Apps Script من جهة الخادم.

## هيكل المشروع

- `index.html` — واجهة التطبيق العربية.
- `api/monjez.js` — وسيط API على Vercel.
- `backend/Code.gs` — كود Google Apps Script الذي يتصل بأوراق Google Sheets.
- `MONJEZ_GAS_URL` — متغير بيئة يضاف في إعدادات Vercel فقط، ولا يضاف إلى GitHub.

## قبل النشر

1. احتفظ بنسخة احتياطية من ملف Google Sheets الحالي.
2. افتح مشروع Apps Script المرتبط بقاعدة بيانات منجز، واستبدل `Code.gs` بمحتوى `backend/Code.gs` في هذا المستودع. لا تحذف أوراق `YAWM_DATA` أو `YAWM_LICENSES` أو `MONJEZ_ACCOUNTS`.
3. شغّل `setupMonjez` مرة واحدة إذا لم تكن أوراق منجز مهيأة مسبقًا.
4. من Apps Script اختر **Deploy → New deployment → Web app**، واجعل التنفيذ باسمك (Me) والوصول **Anyone**، ثم انشر وانسخ رابط `/exec`. يحتاج هذا الإعداد إلى حماية مفاتيح التفعيل داخل منطق الخادم؛ لا تضع رابطًا أو سرًا في الواجهة الأمامية.
5. أنشئ مستودع GitHub جديدًا وارفع محتويات هذا المجلد كما هي.
6. في Vercel اختر **Add New → Project → Import Git Repository**، ثم استورد المستودع. لا تحتاج إلى Build Command أو Output Directory مخصصين لهذا المشروع الثابت.
7. في **Vercel → Project → Settings → Environment Variables** أضف:
   - Name: `MONJEZ_GAS_URL`
   - Value: رابط Apps Script المنشور الذي ينتهي بـ `/exec`
   - Environments: Production، وPreview إذا أردت اختبار الفروع.
8. أعد النشر بعد إضافة المتغير.
9. افتح رابط Vercel واختبر: مفتاح تفعيل جديد، حساب موجود، حفظ عادة، ثم تحديث الصفحة واستعادة الجلسة.

## نشر تغييرات مستقبلية

عدّل الملفات محليًا، ثم ارفعها إلى GitHub. سيقوم Vercel بإنشاء نشر جديد تلقائيًا عند ربط المستودع.

## ملاحظات أمنية وتشغيلية

- لا ترفع ملفات `.env` أو مفاتيح تفعيل حقيقية إلى GitHub.
- هذا المشروع يُبقي بيانات المستخدمين في Google Sheets؛ Vercel يستضيف الواجهة والوسيط فقط.
- مفتاح التفعيل يعمل كبيانات اعتماد للحساب حسب التصميم الحالي. لا تشاركه مع أحد.
- Apps Script Web App العام يستقبل طلبات من وسيط Vercel، لكن كل دالة خلفية يجب أن تتحقق من صلاحية الترخيص والحساب، وهو ما تفعله دوال البيانات الحالية.
- لم يتم ربط المشروع بحساب GitHub أو Vercel الخاص بك ولم يتم النشر تلقائيًا من هذه البيئة. هذه حزمة جاهزة للاستيراد، ويجب إكمال خطوات النشر والاختبار على حسابك.
