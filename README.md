# منجز Pro — النسخة المطوّرة

تم الحفاظ على بنية المشروع الحالية: HTML وCSS وJavaScript عادي، وGoogle Apps Script مع Google Sheets، وواجهة API على Vercel.

## الإضافات في هذه النسخة
- **التقويم:** عرض شهري للمهام، تنقل بين الأشهر، اختيار تاريخ، وعرض/إضافة المهام على التاريخ المحدد.
- **وضع التركيز:** مؤقت 15 أو 25 أو 50 دقيقة، إيقاف مؤقت/متابعة، إعادة ضبط، ربط اختياري بمهمة، وتسجيل الجلسات المكتملة.
- الحفاظ على الهوية الخضراء والذهبية والواجهة العربية الحالية.

## الملفات
- `index.html` الواجهة.
- `api/monjez.js` وسيط Vercel.
- `backend/Code.gs` كود Google Apps Script الحالي.
- `assets/` الصور والشعار.
- `manifest.webmanifest` إعدادات PWA.

## النشر
1. خذ نسخة احتياطية من مستودعك وGoogle Sheets.
2. استبدل الملفات المطابقة في مستودع GitHub بالملفات الموجودة هنا.
3. حافظ على متغير البيئة `MONJEZ_GAS_URL` في Vercel كما هو.
4. لا تغيّر إعدادات Apps Script أو أوراق البيانات لهذه الإضافات؛ ميزات التقويم والتركيز تحفظ حقولها ضمن حالة التطبيق الحالية.
5. اختبر تسجيل الدخول، التفعيل، إنشاء مهمة بتاريخ مختلف، إكمال مهمة، جلسة تركيز، ثم تحديث الصفحة والتحقق من المزامنة.

## ملاحظة
هذه حزمة ملفات مطوّرة، وليست منشورة تلقائيًا على حساب GitHub أو Vercel. يلزم اختبارها على نسخة تجريبية قبل استبدال نسخة الإنتاج.
