# منجز MUNJIZ — مساحة المشاريع المطوّرة

واجهة عربية RTL مبنية على HTML وCSS وJavaScript عادي، مع Google Apps Script وGoogle Sheets ووسيط API على Vercel.

## ميزات مساحة المشاريع
- بطاقات المشاريع مع البحث والتصفية والحالة والإنجاز والموعد والوقت المسجل.
- صفحة مستقلة لكل مشروع.
- مراحل ومهام فرعية مع معرّفات ثابتة.
- لوحة Kanban بسحب وإفلات على الكمبيوتر، وخيار تغيير الحالة على الهاتف.
- قوالب جاهزة، وإمكانية حفظ هيكل المشروع كقالب مخصص.
- تقويم مرتبط بمهام المشروع وتغيير موعد المهمة.
- تحليلات إنجاز ووقت تركيز ومهام متأخرة.
- ملاحظات وروابط ومرفقات محلية صغيرة.
- حفظ محلي ومزامنة عبر آلية التطبيق الحالية.

## الملفات
- `index.html`: الواجهة والمنطق الأمامي.
- `api/monjez.js`: وسيط Vercel الحالي.
- `backend/Code.gs`: كود Google Apps Script الحالي.
- `assets/`: الأصول البصرية.
- `manifest.webmanifest`: إعدادات تطبيق الويب القابل للتثبيت.

## النشر
1. أنشئ نسخة احتياطية من المشروع الحالي.
2. استبدل الملفات المطابقة في مستودع GitHub بالملفات داخل هذه الحزمة.
3. حافظ على متغير البيئة `MONJEZ_GAS_URL` في Vercel.
4. لا تغيّر إعدادات التفعيل أو تمسح بيانات Google Sheets.
5. اختبر الميزات على بيئة تجريبية قبل نشرها للمستخدمين.

## حدود معروفة
- لم يتم إجراء اختبار تكاملي مع حساب Vercel/Google Sheets الفعلي.
- المرفقات المحلية محدودة إلى 150 كيلوبايت لكل ملف وتُحفظ منفصلة عن حالة التطبيق؛ لذلك تكون متاحة على الجهاز الذي أُضيفت منه فقط. للملفات الكبيرة أو المشاركة بين الأجهزة، أضف رابط Google Drive يدويًا؛ لا يوجد رفع مباشر إلى Drive في هذه النسخة.
- السحب والإفلات متاح للوحة Kanban على الكمبيوتر، وعلى الهاتف يوجد تغيير حالة عبر القائمة كبديل للمس. يجب اختبار السلوك على الهاتف الفعلي قبل اعتماد النشر.
- التحليلات الزمنية تعتمد على جلسات التركيز المكتملة المرتبطة بمهام المشروع.
